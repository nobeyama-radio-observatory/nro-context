# 目録の項目の定義

[catalog.yaml](catalog.yaml) は、文脈基盤に関わるすべてのリポジトリの一覧です。人も AI も、まずここを読んでから個別のリポジトリに入ります。

項目の定義の変更は、上流の変更として扱います。判断記録を添えたプルリクエストで行ってください。

## 項目

| 項目 | 必須 | 内容 |
|---|---|---|
| `name` | 必須 | リポジトリ名 |
| `url` | 必須 | リポジトリの URL。まだ作っていなければ空にする |
| `kind` | 必須 | 種別。`hub`（ハブ）、`data`（データ種別のリポジトリ）、`dev`（開発リポジトリ）、`site`（公開サイト）のいずれか |
| `categories` | 必須 | 扱う区分（複数可）。`使命`、`資産`、`業務`、`数値`、`経緯`、`外部` から選ぶ。ハブは空でよい |
| `description` | 必須 | 何のリポジトリか。一、二文で書く |
| `owner_role` | 必須 | 担当の役割。個人名ではなく役割で書く。未定なら `未定` |
| `update` | 必須 | 更新の頻度。`随時`、`月次`、`年次`、`開発に応じて` など |
| `disclosure` | 必須 | 公開の区分。`公開`、または `公開（一部は所在のみ）` |
| `status` | 必須 | 状態。`準備中`、`稼働`、`暫定`、`保守のみ`、`archive` のいずれか |
| `related` | 任意 | 関係するリポジトリの `name` の一覧 |
| `note` | 任意 | 補足 |

## 書き方の決まり

- 1件のリポジトリにつき1項目とします。
- 非公開のリポジトリや場所は載せず、[非公開の一覧](../policy/non-public.md)に記します。
- 観測所の組織の外にある開発リポジトリ（個人のアカウントにあるものなど）も、文脈に関わるなら載せます。
- 現状サマリー（`summary/`）は、将来この目録をもとに自動で作ります。

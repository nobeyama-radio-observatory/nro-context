# 経緯

7つの区分のうち「経緯」の一部として、観測所の装置と運用形態がこれまでどう変わってきたかを、公開資料から年表にまとめます。判断記録（[decisions/](../decisions/)）が文脈基盤を始めてからの判断を記録するのに対し、ここはそれより前の出来事の要約です。データ種別のリポジトリに切り出すまでは、ハブに置きます。

確認日：2026-11-18

## 読み方

- **各行は事実です。** 出典を添えています（[0004](../decisions/0004-事実の根拠は出典で示す.md)）。出典は、断りがなければ一次資料（国立天文台、観測所、日本天文学会の年会の講演予稿）です。一次資料でないものには「二次」と書きます。
- **理由は、出典に書かれているものだけを書きます。** 書かれていない理由を補うときは、仮説か推測と明示します。
- **出典を示せなかった事柄**は、末尾の「確かめられていないこと」に分けています。
- **範囲：** 公開資料に残る出来事だけです。所内の検討と見送った案は、公開資料にほとんど残っていないので、まだ入っていません（末尾の「この節に足りないもの」）。

## 外部評価の指摘

2023年度の外部評価の報告書（外部評価2023）は、観測所の今後について次のように述べています。将来の選択肢を考えるときの前提になります。

- 今の予算の制約のもとで、野辺山、水沢、ASTE の3施設を同じ水準で運用し続けるのは難しいとみる。3施設のうち1施設を閉じて予算を他の2施設に回す道を含め、検討するよう求める。3施設が技術者や事務の職員を共有し、年のうちの時期をずらして運用する案も挙げる。
- 観測所は少なくとも年 3,000 時間の運用を目指すべきで、これ以上の運用の縮小は勧めない。それが難しければ、施設全体を閉じることを真剣に検討するよう求める。
- 報告書は、2017年度（45m 鏡のレガシープロジェクトの評価）と 2018年度（全体の評価）の外部評価の指摘への対応も評価の項目にしている。

## 確かめられていないこと

公開資料で確かめられなかった事柄です。所内の記録や聞き取りで確かめる候補です。

- BEARS、S40、S100 など、主な受信機と分光計の搭載の年と共同利用への公開の年（2000〜2003年度の年次報告には記載が見つからない）
- ミリ波干渉計の6台目の追加（1994年）と Rainbow 観測（2000年）の一次資料
- ミリ波干渉計のアンテナのうち、再利用された1台を除く行き先
- 電波ヘリオグラフの 2020年以降の装置の扱い
- ラージプログラムの枠を始めた年度（2016年度の年次報告に初めて出てくる）
- 共同利用の終了を決めた国立天文台の文書（運営会議など）と、その理由。運営費交付金の減少との関係は、2022年の将来シンポジウムの財務の資料（https://www.nao.ac.jp/for-researchers/naoj-symposium2022/pdf/NAOJFutureSympo2022-Saito2.pdf ）が第3期中期目標期間の交付金の減少を示すだけで、直接の記述は見つからない
- 2017年度と 2018年度の外部評価の報告書の中身
- 有料望遠鏡時間の開始の時期の表記：[mission/](../mission/README.md) は案内のページに基づき「2022年6月からの導入として案内されている」とし、年次報告2022 は第41期を 2022年9月1日に開始したとする。公募の開始と観測の開始の違いとみられるが（推測）、確かめていない

## この節に足りないもの

公開方針の「経緯」には、判断の記録に加えて、過去の検討と見送った案が入ります。この年表は、何が起きたかは示せますが、どんな案を比べて何を見送ったかはほとんど示せません。所内の会議の記録の要約や、経緯を知る人への聞き取りで足す必要があります（#23）。

# 使命

7つの区分のうち「使命」（目的、中期計画、法令、関係者）を置きます。データ種別のリポジトリに切り出すまでは、ハブに置きます。

## 文脈基盤の目的

観測所が自らを記述した「文脈基盤」を、公開を原則として育てます。これ一つで、次の三つの目的を同時に満たします（[0001](../decisions/0001-文脈基盤と公開の進め方を採用する.md)）。

1. **AI による上流の支援：** 大掛かりな業務改善、システムとソフトウェアの統合整理、新規事業、ビジョン策定の補助を AI から得ます。
2. **データの集約と外部の参加：** 装置や運営の情報を公開し、業務改善に必要なデータを集めるとともに、天文台外の人が開発などに参加しやすくします。
3. **説明責任：** ステークホルダーに対して、観測所が何のために存在し、どう運営されているかを示します。

## 観測所の目的と中期計画

正本は各機関の公開資料です。ここには所在と、観測所に関わる部分の要約だけを書きます。内容が変わったら正本を見直し、ここの要約と確認日を直します。

### 位置づけ

野辺山宇宙電波観測所は、国立天文台の観測施設です。国立天文台は、大学共同利用機関法人 自然科学研究機構が設置する大学共同利用機関の一つです。

### 観測所の目的と使命（Scientific Goals and Missions）

国立天文台は、プロジェクトごとに Scientific Goals and Missions（目的、使命、主要科学達成目標、達成期限）を定めています。野辺山宇宙電波観測所のものは次のページにあります。

- 所在：https://www.nao.ac.jp/recommend/mission/nro.html
- **目的（Purpose）：** 45m 電波望遠鏡を用い、星形成ならびに星間物質の研究を通じてミリ波天文学を推進する。
- **使命（Missions）：** 野辺山 45m 電波望遠鏡を用いた科学研究のための観測機会ならびに開発機会を、世界の科学コミュニティへ供する。
- **主要科学達成目標（Primary Scientific Goals）：**
  - CO 分子輝線を用いた広域観測により、天の川銀河系の星形成と星間物質の研究を推進する。
  - 重水素輝線を用いた高感度観測により、星形成の研究を実施する。
- **達成期限（Target Date）：** 2028年3月末。機構の第4期中期目標期間の終わりと同じです。

- **［38］** 運営会議などで研究者コミュニティの意見を聞き、運営に反映する。各機関は、関連する学会や主催する研究会などでも研究者コミュニティの各層の意見を聞く。あわせて、議事録の公開と運営状況の情報発信により、開かれた運営を進める。観測所での具体的な仕組みは、次の「法令と規程」の科学諮問委員会の項を参照してください。

### 国立天文台の将来計画（第5期中期計画期間 2028〜2033年度に向けて）

国立天文台は、将来計画を三段構えで策定しています（将来計画策定プロセス https://www.nao.ac.jp/for-researchers/naoj-futureplan/future.html ）。

2. 国立天文台が推進すべきサイエンスのロードマップ（国立天文台サイエンスロードマップ）
3. それを実行するためのプロジェクトの実施計画（国立天文台実施計画）

サイエンスロードマップのうち、観測所に関わる記述は次のとおりです。

- **目的：** 第5期中期計画期間（2028〜2033年）とその先に、国立天文台がどのようなサイエンスをどう推進するかを示し、実施計画の策定に戦略的指針を与える。実施計画では、実現性の評価と資源配分がより厳密に行われる。
- **野辺山 45m 鏡の提案：** コミュニティから寄せられた提案のうち、ID33「野辺山45m鏡を用いた次世代技術開発とミリ波大口径アンテナによる天文学」は、地上望遠鏡プロジェクトの「優先度が高い提案」に分類された（§3.3.1.2）。波長 3mm 帯で世界トップクラスの性能を維持する 45m 鏡で、アルマ望遠鏡と相補的な広域探査を行う提案で、次世代技術の開発と若手の人材育成への寄与も評価されている。
- **観測所の運用：** §3.5 で、運営費交付金を用いた観測所運用である野辺山宇宙電波観測所と水沢 VLBI 観測所は、生み出すサイエンスの価値とコミュニティからの期待のバランスを取りながら、運用形態や規模、資金獲得手段などを工夫していく必要がある、としている。
- **全体の制約：** 国立天文台の人的・資金的リソースは切迫しており、第5期中期計画期間にすべての既存プロジェクトを維持・発展させる余地は非常に少ない、としている（§3.5）。

### 科学諮問委員会

研究者コミュニティの意見を共同利用の運用に反映する仕組みです。

- 根拠：国立天文台科学諮問委員会規則（2023年9月8日施行の版）https://www.nao.ac.jp/contents/about/boards/science-advisory-committee/1-23-kagakushimon20230908.pdf
- 委員会は、共同利用などに関して必要なことを議論するために、対応するプロジェクト室などに置かれます。台長の諮問に答申し、台長に意見を述べます。大型装置の共同利用を中心とした運用について議論します。
- 委員は対応するプロジェクト室などの構成員以外の者で組織し、任期は2年です。必要に応じて、委員会の下に共同利用時間割り当て委員会（TAC）を置きます。
- **野辺山宇宙電波観測所を所轄するのは ALMA 科学諮問委員会です。** 日本アルマ科学諮問委員会（Japanese ALMA Science Advisory Committee、JSAC）とも呼ばれます。規則の別表で、アルマプロジェクト、野辺山宇宙電波観測所、ASTE プロジェクトの三つに対応します。野辺山専用の科学諮問委員会はなく、JSAC が兼ねています。
- 45m 電波望遠鏡の有料望遠鏡時間の案内でも、JSAC が承認した将来装置の試験が利用目的の一つに挙げられています。

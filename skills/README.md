# スキル

観測所全体で使う Claude のスキルの正本です（[0002](../decisions/0002-スキルの正本をGitHubに置く.md)）。

| スキル | 役割 |
|---|---|
| [nro-context](nro-context/SKILL.md) | 文脈基盤への入口。ハブの目録と進め方の決まりを最初に読ませる |
| [worklog](worklog/SKILL.md) | ヒアリング型の業務ログ。記録、検索、棚卸し、月次マージ |

## 決まり

- **ここが正本です。** 所員の手元に届く組織配布のスキルは、ここから作る写しです。配布物を直接直さず、ここを直してプルリクエストを出します。
- **観測所全体で使うものだけを置きます。** 特定のリポジトリに結びつくスキルは、そのリポジトリに置き、目録には所在だけを載せます。
- **`.claude/skills/` には置きません。** そこに置くと、このリポジトリの中で Claude Code を起動したときにしか読み込まれないためです。
- **公開リポジトリなので、スキルにも機微情報を入れません。** 例に出す人名は「Aさん」のように置き換え、パスや設定は利用者ごとの `CONFIG.md` などに分けます。

## 配布の手順（当面は手作業）

1. スキルの変更をプルリクエストで取り込む。
2. 管理担当が、変更したスキルのフォルダを zip にまとめ、組織配布（claude.ai の組織のプラグイン）を更新する。
3. 更新したことと、取り込んだプルリクエストの番号を、そのプルリクエストにコメントで残す。

慣れてきたら、zip の作成を `.github/workflows/` で自動化します。

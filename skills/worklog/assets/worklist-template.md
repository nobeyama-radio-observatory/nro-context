## 列の意味

- **タグ** — `#業務グループ/個別業務` の2階層。第1階層はタグ辞書の固定語彙から選ぶ
- **頻度・時期** — 引き継ぎ時に「いつ発生するか」が最重要。年1回の業務ほど漏れる
- **関係者** — 必ず埋める。単独なら「単独」
- **属人度** — 高/中/低。**業務の側**から見て、現状どれだけ一人に集中しているか
- **判断レベル** — L1〜L5。**人の側**から見て、その業務の判断をどこまで任されているか（下表）
- **手順・資料の在りか** — 空欄なら「記憶の中にしかない」ということ
- **状態** — 現行/終了。終了しても行を削除せず、備考に終了年を記す

属人度と判断レベルは同じ事実を両側から見たもの。属人度は「渡せていない度合い」、
判断レベルは「受け取った度合い」。引き継ぎが進むと、渡す側の属人度が下がり、
受け取る側の判断レベルが上がる。この2列が同時に動くのが、引き継ぎが成立した状態。

## 判断レベル（L1〜L5）

医学教育の EPA（Entrustable Professional Activities）の考え方を借りている。
**「何を知っているか」ではなく「監督なしで任せられるか」** で段階を定める。
保守業務では、知識よりも「単独で判断してよい範囲」のほうが実態に近いため。

| | 状態 | 判定の目安（記録から読み取れる事実） |
|---|---|---|
| L1 | 見学のみ。単独では実施しない | 立ち会った・説明を受けた |
| L2 | 監督下で実施。判断は経験者が行う | 経験者と一緒に作業した |
| L3 | 単独で実施するが、判断に迷えば相談する | 単独で着手し、途中で相談した |
| L4 | 単独で判断し完結できる | 相談なしで完結した |
| L5 | 他者に教え、他者の判断を監督できる | 後任・後輩と一緒に作業した／説明した |

### この列の扱い

- **記入するのは本人。** 日々の記録から AI が段階の変化を検知して提案するが、確定は本人が行う。
- **低いことは問題ではない。** 新しい業務に関わり始めれば L1 から始まる。それが正常な状態。
  流動化を進めるほど L1・L2 の行は増える。増えていることは、越境が起きている証拠。
- **人事評価の資料ではない。** 月次マージで集約するのは、業務ごとに
  「単独で判断できる人が何人いるか」を見るため。個人の序列をつけるためではない。
  属人度と同じく、**組織側のリスク指標**として使う。
- **L4/L5 がその業務に一人しかいない行は、属人度「高」と同じ意味を持つ。**
  手順書が整っていても、判断を任せられる人が一人なら引き継ぎは成立していない。
  手順の文書化では埋まらない種類の穴なので、別立てで見る価値がある。

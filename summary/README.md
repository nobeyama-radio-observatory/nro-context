## 全体の段階

- **フェーズ1（文脈基盤の整備）の立ち上げ中です。** ハブの骨組み、進め方の決まり、公開方針、判断記録の始まりの3件、Claude の入口がそろいました（[0001](../decisions/0001-文脈基盤と公開の進め方を採用する.md)）。
- 最初の目標だった資産の台帳の初版は、ハブの `assets/` に置きました（0005）。その時点で上流の問いの最初の試行を行いました（下記）。
- 資産の情報の正本を、装置群ごとの運用リポジトリに移すことにしました（0006）。最初の分光計（`nro-45m-spectrometer`）は作成済みで、2026-11-18 の聞き取りで、3件の台帳の未記入（保守の手間、担い手の数、更新の見込み、担当の4項目）を埋めました。2つ目の受信機（`nro-45m-receivers`）も作成し、2回目の聞き取りで7件の未記入を埋め、T70 を廃止に、eQ を新規に加えました。3つ目のアンテナ（`nro-45m-antenna`）では、大きな改修が要る部分（アンテナ制御ユニット、マスターコリメーター、AZ レール）と、その規模の見立てを聞き取りました。4つ目の観測制御（`nro-45m-control`）では、計算機の更新と web UI 化の予定を聞き取りました。続けて、データの保管（`nro-data`）と利用者向けのツール（`nro-user-tools`）を作り、聞き取りました。並行して、業務と数値の区分を始めることが残っています。
- フェーズ2（運営の仕組み）には、上流の問いに根拠を示して答えられるようになり、判断記録が蓄積したときに移ります。

## 全体の段階

- **フェーズ1（文脈基盤の整備）の立ち上げ中です。** ハブの骨組み、進め方の決まり、公開方針、判断記録の始まりの3件、Claude の入口がそろいました（[0001](../decisions/0001-文脈基盤と公開の進め方を採用する.md)）。
- 最初の目標は、資産の台帳（`nro-assets`）の初版です。初版ができた時点で、上流の問いを初めて AI に投げます。
- フェーズ2（運営の仕組み）には、上流の問いに根拠を示して答えられるようになり、判断記録が蓄積したときに移ります。
